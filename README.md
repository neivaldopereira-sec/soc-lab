# SOC Lab

Laboratório de cibersegurança com foco em simulação de ataques e análise de logs (SOC).

## Objetivo
Simular cenários reais de ataque e realizar detecção e análise de incidentes utilizando SIEM.

## Ambiente
- Virtualização: VirtualBox
- SIEM: Wazuh
- Sistemas:
  - Ubuntu (Linux)
  - Windows

## Etapas do Projeto
1. Criação do ambiente virtual
2. Simulação de ataques
3. Coleta de logs
4. Análise de incidentes
5. Resposta e mitigação
